# 덩굴숲

앙리 루소의 정글을 헤치며 마술적 사실주의의 기적을 찾아다니는 웹게임.
납작한 그림판들이 무대 세트처럼 간격을 두고 서 있고, 그 사이를 캐릭터 뒤에서 따라가며 걷는다.
판은 늘 카메라 쪽으로 돌아서서 어느 방향으로 돌아봐도 그림 정면이 보인다. 바람이 불면 윗부분이 흔들린다.

루소 그림에서 가져온 것들: 「적도의 정글」의 식물들, 「꿈」의 바나나 잎과 연꽃, 「뱀 부리는 여인」의 홍학과 큰 달,
「놀람!」의 수풀 속 호랑이와 열대 폭풍, 「이국적 풍경」의 오렌지 든 원숭이, 「해 질 녘의 처녀림」의 크고 붉은 해.
낮과 밤, 폭풍(5분마다 50초)은 실제 시각에 맞춰 돌아가서 같이 접속한 사람은 같은 하늘을 본다.

숲에는 벽이 없다. 동쪽 끝으로 계속 걸으면 서쪽에서 다시 들어오고, 지평선은 작은 행성처럼 둥글게 휘어 보인다.

**모닥불 공터**: 출발점에 모닥불이 있다. 곁에 가면 메뉴가 뜨고, 둘러앉기(F), 구운 바나나·군옥수수·망고 굽기(G), 마림바·마라카스·북 연주(1~8)를 할 수 있다. 연주는 근처 사람에게 들리고, 다 익은 음식은 다 같이 나눠 먹는다. 함께 먹은 기록은 그림첩의 모닥불 일지에 남는다.

**가만히 있으면 나오는 것들**: 숲은 늘 그림처럼 빽빽하게 시야를 둘러싸고, 화면 가장자리엔 앞쪽 풀잎이 액자처럼 걸려 있다. 잠시 가만히 서 있으면 원숭이 무리, 흰 새, 큰부리새, 나무늘보가 잎 사이로 나온다. 화면 가운데에 두고 잠시 바라보면 손글씨 이름표가 뜨고 그림첩의 관찰 기록에 남는다. 마우스로 위아래도 볼 수 있다.
같이 들어온 사람과 위치와 말이 실시간으로 보이고, 앵무새는 숲에서 들은 말을 기억했다가 따라 한다.
기적을 발견하면 멕시코 봉헌화(레타블로) 형식의 카드가 그림첩에 한 장씩 모인다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 (무대 세트식 3인칭, three.js) |
| `2d.html` | 예전 버전 (위에서 내려다보는 2D) |
| `config.js` | Supabase 연결 정보 (비워두면 혼자 하는 버전) |
| `supabase.sql` | 앵무새 기억용 테이블. Supabase SQL Editor에서 한 번 실행 |
| `assets/` | 그림 파일 (없으면 색으로 그림) |

## 그림 넣기

`assets/`에 아래 이름의 png를 넣으면 바로 그 그림판으로 바뀐다. 없는 파일은 기본 그림으로 그려진다.
모두 **정면에서 본 모습**, 투명 배경, 아래쪽이 땅에 닿는 그림. 비율만 맞으면 크기는 자유(픽셀 아트는 2배, 3배로 그려도 선명하게 나온다).

덤불 칸마다 식물 그림판 세 장이 앞뒤로 서고, 지나가면 옆으로 젖혀진다.
루소의 그림은 모두 퍼블릭 도메인이라, 위키미디어 공용(commons.wikimedia.org)의 그림에서 식물이나 동물을 오려 투명 배경 png로 넣어도 된다.

|---|---|---|

## 실행

- 내 컴퓨터: 폴더에서 `npx serve` 후 브라우저로 열기 (또는 VS Code Live Server)
- GitHub Pages: 저장소 Settings → Pages → Branch를 `main` / `root`로 저장. 잠시 후 `https://jynsol.github.io/jungle/`에서 열린다

## 멀티플레이 켜기 (Supabase)

1. Supabase에서 프로젝트를 하나 만든다
2. SQL Editor에 `supabase.sql`을 붙여넣고 Run
3. Project Settings → API에서 Project URL과 anon key를 복사해 `config.js`에 넣는다

위치와 채팅은 저장되지 않고 그 자리에 있는 사람끼리만 주고받는다. 앵무새가 배운 말만 `parrot_lines` 테이블에 남는다.
그림첩과 내 위치, 이름은 각자 브라우저에 저장된다.

## 조작

- 걷기: WASD·방향키, 휴대폰은 화면 왼쪽을 누른 채 끌기
- 돌아보기: 마우스로 끌기 또는 Q·E, 휴대폰은 화면 오른쪽을 끌기 (360도)
- 말하기: Enter
- 덤불 속으로 그냥 걸어 들어가면 헤치고 지나간다
